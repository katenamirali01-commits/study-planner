# 📚 Планировщик учёбы

Простой сайт для планирования учебного дня. Можно добавлять задачи, указывать время (например, 8:00–9:00), отмечать выполненные и следить за прогрессом.

🔗 **Сайт:** https://katenamirali01-commits.github.io/study-planner/

## Что умеет
- Добавление и удаление задач
- Необязательное время для каждой задачи
- Отметка «выполнено» и полоска прогресса
- Сохранение задач в браузере (не пропадают после обновления)

## Технологии
